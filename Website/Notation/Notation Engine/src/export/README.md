# src/export

SVG -> PNG rasterization (`raster.ts`, `png.ts`), direct SVG export
(`svg.ts`), multi-page PDF export (`pdf.ts`), and compressed MusicXML
(`mxl.ts`), which writes the `.mxl` archive `unzipMxl` reads.

See `../Notation Plan/PLAN.md` Part G (timing, playback and export
correctness), which records the raster-slice and PDF-page behaviour.
