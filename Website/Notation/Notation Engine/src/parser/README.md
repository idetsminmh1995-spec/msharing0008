# src/parser

MusicXML (`musicxml/`) and MIDI (`midi/`) -> the core data model in
src/core. The MusicXML reader handles files exported by any software --
the fixture corpus is the evidence, and it holds real exports from several
different authoring programs.

See `../Notation Plan/PLAN.md` Part D (import compatibility and MIDI scope)
for what is decided and what is still open.
