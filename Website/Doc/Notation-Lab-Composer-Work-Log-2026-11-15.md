# Notation Lab Composer — Retired Work Log

**Retired:** 2026-11-15

The browser-local score composer described in this historical work log was removed after the Notation Lab product flow was reset.

Notation Lab now starts with an **Open File / Create / Scan** entry page and hands users to a dedicated Editor route. The composer-first interface is not part of the active product direction and must not be restored without an approved update to the Notation Lab UI/UX Plan.
