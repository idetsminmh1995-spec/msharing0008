# 3D Model

Repository home for 3D instrument-scene models and their supporting metadata for piano, guitar, bass guitar, violin, and related instruments.

This folder is an organizational starting point only. Existing production assets remain at their current paths; for example, the piano hand-pair GLB is `website/assets/hand/hands_pair.glb` and is still referenced by the piano video renderer. Do not duplicate or move production assets here until their code references, manifests, cache versions, licenses, and tests are updated together.

For each model added here, record its source and license, intended instrument, units and coordinate frame, transforms and named anchors, rig/bone mapping, supported hand or prop roles, and relevant calibration or rendering tests.
